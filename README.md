# Personal Portfolio Website

A personal portfolio web application built to display my profile, engineering skills, academic background, professional certifications, and technical experience.

## Features
- **About Me Section**: Overview of my technical profile, experience, and background.
- **Work Experience**: Details of my career as an IDC QA Administrator at National Data Center (AOS).
- **Education & Certifications**: Academic qualifications including my A1 Diploma, current A0 Degree at SJITC, and professional certifications (CompTIA A+, Network+, Server+, NOC).
- **Projects Showcase**: Summary of completed projects including descriptions, deliverables, and timelines.
- **Contact Information**: Direct communication channels for technical networking and collaboration.

## How to run this project
You can access this project online via the GitHub repository or preview it locally on your machine.

### Prerequisites
To view or run this project locally, you need to have:
- A modern web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge)
- Git installed on your computer
- A code editor such as VS Code (optional)

### Installation
Follow these steps to run the project locally:

Step 1: Clone the repository
```bash
git clone [https://github.com/IraCynthia/Cynthia.git](https://github.com/IraCynthia/Cynthia.git)
```
Step 2: Navigate to the project directory

```Bash
cd Cynthia
```
Step 3: Open the project
Open `index.html` directly in your browser or run it using VS Code Live Server.
